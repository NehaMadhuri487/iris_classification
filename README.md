## Project Overview

This project implements a Machine Learning classification model that predicts the species of an Iris flower using its sepal length, sepal width, petal length, and petal width measurements.

The model is trained on the well-known Iris dataset and can accurately classify flowers into the following categories:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

---

## Features

* Data loading and preprocessing
* Train-test data splitting

## Dataset Information

The Iris dataset contains 150 flower samples with the following attributes:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width
* Species (Target Variable)

Species Classes:

1. Setosa
2. Versicolor
3. Virginica
